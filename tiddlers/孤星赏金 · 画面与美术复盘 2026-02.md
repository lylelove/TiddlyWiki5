# 孤星赏金 · 画面与美术复盘

项目：`D:\work\web\west`（纯前端零依赖 Canvas 2D Roguelike，480x270 逻辑分辨率，像素美术全部是代码内点阵字符串）

## 这轮做了什么

围绕画面表现与美术资源做了一轮改造，重点是**消除视觉硬伤**而不是加新内容。

### 1. 修掉分块接缝（最关键的修复）

**问题**：七种地貌里多条横向纹理（峡谷岩层、沙漠沙丘脊线、铁轨、小镇木板路、酒馆地板、矿洞矿车轨道）原本按分块局部坐标 `rnd()` 随机生成，128px 分块边界处必然错线。灰调时期被掩盖，改成暖色分级后非常刺眼。

**做法**：新增世界坐标确定性哈希 `wh(wx, wy, s)`，所有长条纹理改为按世界坐标取值；再加 `paintRows()` 逐行把连续同色像素合并成一次 `fillRect`，兼顾逐像素判定的精度与绘制调用数。

**教训**：地形纹理必须世界坐标锚定。用分块局部随机数画跨块图案，接缝是必然的。

### 2. 地貌色彩分级

每个分块生成后叠一层低饱和 `overlay` 色，让地表、岩层与道具共享同一色温。

**走过的弯路**：最初把叠加放在 `decor()` 之前，结果系统色阶画出的岩台保持冷灰，与染色地面各说各话。正确顺序是**先画完所有内容再统一分级**。

### 3. 调色板转向暖边境色阶

原来是黑白灰 8 阶加三个高饱和焦点色。改为深墨描边 + 皮革/尘土中间调 + 旧纸高光，新增幽灵冷青与沙尘赭金。中性灰的烟尘粒子一并改暖，但**保留幽灵的冷青色**——冷色是幽灵的身份特征，不能一起暖掉。

### 4. 结构物重画

建筑从纯方块改成有假门面、门廊立柱、遮阳篷、挂招牌的西部轮廓；新增岩台、枯树、墓碑十字、白骨等道具；矿洞与酒馆加径向渐变暖光源。

### 5. 反馈与氛围

- HUD 加半透明背板（保证任何地貌与弹幕下都可读），弹巢加黄铜质感，低血脉冲警示
- 爆炸改成固定角度火舌拼出的不规则火团，替代原来的标准圆环
- 新增受伤红屏脉冲、翻滚残影、子弹曳光、地貌切场过渡、暗角
- 修复头目血条与横幅在屏幕顶部重叠的 UI 缺陷

## 踩到的坑

- **矿洞读成星空**：逐像素高频噪点密度过高。改用低频大块噪声 + 像素抖动后读作岩面。
- **8x8 规整方块**：整格阈值判定会让簇边界呈直角，像砖墙。加 `(hash-0.5)*抖动` 打散。
- **爆炸像甜甜圈**：同心圆叠加必然读成几何图形。改用固定角度（每帧形状稳定、不闪烁）的不规则火舌。
- **小尺寸图标糊成一团**：12px 画布塞不下复杂轮廓。双管霰弹枪、杠杆步枪、闪避、召唤四个图标重画为高对比剪影。
- **`tools/smoke.js` 桩件落后于游戏代码**：`querySelectorAll`、`navigator`、`createRadialGradient` 都缺失，导致测试直接崩。桩件是过时的一方，补全它。

## 新增的自动化校验

`tools/smoke.js` 里把精灵行宽检查从"仅提示"升级为**硬性失败**，并新增：
- 点阵字符必须在调色板内（防止把 `k` 打成 `K` 这类静默缺像素）
- 不能有空精灵

## 验证结果

- `node tools/smoke.js 150 2 --full` → SMOKE PASS，七种地貌 7/7、三个头目 3/3、600 秒触发胜利，单步逻辑 3.85ms（未退化）
- 用 headless Chrome 实拍七种地貌逐张审查，并放大局部核对纹理与图标
- 冒烟测试的 Node canvas 是 Proxy 桩件，**`overlay` 混合模式在那边是空操作**，色彩分级只能靠真实浏览器截图验证

## 新增工具能力

截图钩子加 `&biome=0..6` 锁定地貌，用于单独审查七种地貌；锁定时时间压在低难度区间，否则敌人会堆满画面盖住地形。这是本轮很重要的一个发现：**地貌取景必须与难度解耦**。
