# 孤星赏金 LONESOME BOUNTY

西部牛仔题材的极简黑白灰像素风 2D Roguelike 生存游戏（类《吸血鬼幸存者》），按 1 小时 Game Jam 规模交付。

- 工作区：`D:\work\web\west`（浏览器直接打开 `index.html` 即可，零依赖、零素材）
- 交付日期：2026-10-07 会话
- 规模：`index.html` + 5 个 JS 模块（core / sprites / world / entities / game）+ 2 个 Node 测试脚本

## 关键技术决策

1. **美术零素材**：全部像素图形写成字符点阵数据（`js/sprites.js`），运行时烘焙成离屏 canvas。调色板只有黑白灰 8 阶 + 三种高饱和色（枪火黄 #ffd24a、血橙 #ff6a2a、仙人掌绿 #63c46a）做视觉焦点。
2. **音频零素材**：WebAudio 参数化合成。左轮/霰弹/步枪用噪声包络 + 低频正弦，马蹄用高通噪声 + 三角波，配乐是五声音阶口琴旋律 + 滑棒吉他弯音 + 马蹄节奏 + 低频鼓，另有循环风声噪底；音乐强度随生存时间提升。
3. **地形分块按需生成**：128px 一块，纹理烘焙进 canvas 并做 LRU 缓存（上限 260 块），静态碰撞体随块存。地貌每 85 秒推进一次，切换时清空缓存。世界无限大，只有一份生成代码。
4. **中文界面用 DOM，战斗 HUD 用 canvas**：通缉令版式（标题 / 升级三选一 / 暂停 / 结算）用 DOM 拿到中文排版；HUD 用自写 3x5 点阵字体保持像素感。
5. **逻辑分辨率 480x270，整数倍放大**（近邻采样），窗口变化重算缩放。

## 平衡数据（脚本实测，走位机器人）

- 曲线：`赏金需求 = 6 + 6L + 0.5L²`；实测 150 秒到 LV15~17，击杀 600~700，屏幕常驻 100~300 敌。
- 赏金碎片会主动追人（越久越快，14 秒超时自动结算）——早期版本碎片追不上玩家，导致升级曲线断裂，这是本项目最关键的一次平衡修正。
- 敌人数量上限 480，且**裁剪时跳过头目**（曾出现「满员裁剪把头目静默删掉」的缺陷，已加回归检查）。

## 验证方式

- `node tools/smoke.js 180 2 --full`：DOM/Canvas/Audio 三套桩件把游戏跑在 Node 里，含资源自检、武器曲线单调性、音频代码全路径可执行、两局对局模拟、头目裁剪回归、不死模式跑满 10 分钟（验证三头目出场 / 七地貌经历 / 600 秒胜利）。
- headless Chrome 截图 + `--dump-dom` 标题钩子确认真实浏览器零异常；内置 `?shot=title|play|levelup|boss|pause|win&t=秒数` 取景钩子。
